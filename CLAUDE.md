# SDRCraft

Pure-Rust receive-only radio workstation. Read `AGENTS.md` before editing.

Crates: `sdrcraft-core`, `sdrcraft-mcp`, `sdrcraft-app`. No path dependency on `rust-sdr-mcp` or `sdr-mcp`.

Do not add a transmit command. Hardware that can send, and the explorer locator beacon, are described in `docs/TRANSMIT_BOXES_AND_BEACONS.md`.
